# agent-mods

Claude Code の mod 集です。

| mod | できること | なぜ作ったか |
|---|---|---|
| [nametag](mods/nametag/README.md) | セッションに色と名前を自動で付けます | セッションを並べると、どれが何の会話か分からなくなります。組み込みの `/color` と `/rename` は自分で打つもので、`/rename` は名前の付け方も変えられません |
| [pn](mods/pn/README.md) | `/pn:pr` で、開いている PR の一覧を手元に出します | GitHub を見に行かずに、PR の様子が分かるようにしたいです。レビューしたい PR は、リンクをコピーしてそのまま扱えます |

インストールの方法と、各 mod が送るもの・実行するものは、それぞれの README にあります。
