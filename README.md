# agent-mods

Claude Code の mod 集。

| mod | できること | なぜ作ったか |
|---|---|---|
| [nametag](mods/nametag/README.md) | セッションに色と名前を自動で付ける | セッションを並べると、どれが何の会話か分からなくなる。組み込みの `/color` と `/rename` は自分で打つもので、`/rename` は名前の付け方も変えられない |
| [pn](mods/pn/README.md) | `/pn:pr` で、開いている PR の一覧を手元に出す | GitHub を見に行かずに、PR の様子が分かるようにしたい。レビューしたい PR は、リンクをコピーしてそのまま扱える |

インストールの方法と、各 mod が送るもの・実行するものは、それぞれの README にある。
