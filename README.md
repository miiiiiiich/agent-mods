# agent-mods

Claude Code の mod 集です。

| mod | できること | なぜ作ったか |
|---|---|---|
| [nametag](mods/nametag/README.md) | セッションに色と名前を自動で付ける | セッションを並べると、どれが何の会話か分からなくなる。組み込みの `/color` と `/rename` は手で打つもので、`/rename` は名前の付け方を変えられない |
| [pn](mods/pn/README.md) | `/pn:pr` で開いている PR の一覧を手元に表示する | GitHub を見に行かずに PR の様子を確認したい。レビューしたい PR はリンクをコピーしてそのまま使える |

インストールの方法と、各 mod が送るもの・実行するものは、それぞれの README にあります。
